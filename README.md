# Responsive Personal Portfolio Website

A clean, semantic, and mobile-first personal portfolio website designed to showcase a developer's profile, technical skill set, featured projects, educational background, and contact channel. Developed according to the Veda Technology internship task specifications.

---

## 🎯 Approach

1. **Semantic Structure & Clean HTML5:**
   - Structured content using standard semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) to promote search engine optimization (SEO) and web accessibility (a11y).

2. **Mobile-First & Fluid CSS3 Architecture:**
   - Utilized CSS Custom Properties (variables) for consistent color palettes, typography, and spacing.
   - Built layout grids with **CSS Flexbox** (for navigation bars and button groups) and **CSS Grid** (for projects and skill cards).
   - Integrated responsive media queries at standard breakpoints to maintain proportional UI layout across mobile phones, tablets, and desktop displays.

3. **Vanilla JavaScript Functionality:**
   - Implemented an accessible mobile navigation hamburger menu that toggles states dynamically and closes automatically on anchor selection[cite: 1].
   - Implemented client-side form validation verifying non-empty fields, proper regex-based email formats, and string length boundaries prior to dispatch[cite: 1].
